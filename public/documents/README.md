# Documents

Placez ici les documents à afficher dans Collabora : DOCX, DOC, ODT, PPTX,
PPT, ODP, XLSX, XLS, ODS, PDF, etc. Les sous-dossiers sont pris en charge.
Ils apparaissent automatiquement dans `C:/User/Documents` et s’ouvrent dans
une fenêtre en lecture seule. Les nouveaux fichiers sont détectés en dev ;
en production, reconstruisez le portfolio pour actualiser la liste.

Le CV est désormais stocké dans `src/C:/User/Document/CV V2.docx`, configuré dans
`src/C:/Program Files/CV.webapp` via le champ `document`.

Ce dossier est public : son contenu est téléchargeable par les visiteurs.
